vorbis_synthesis_loss_notify

declared in "vorbis/codec.h";

This function performs packet-loss concealment on a decoding vorbis_dsp_state. It is called once, in stream order, for every whole audio packet that the transport has confirmed lost, and before the next successfully received packet is passed to vorbis_synthesis() and vorbis_synthesis_blockin(). For a run of consecutive losses it is called once per lost frame; any PCM made available by each call must be drained with vorbis_synthesis_pcmout() / vorbis_synthesis_read() before the next notification.

The lost frame is treated as a silent block of the same geometry as the preceding block. The retained overlap half is windowed out so the output fades smoothly to silence, and a zeroed half is stored for the next real block to overlap. Ring-buffer geometry, center-window toggling and sample accounting are kept identical to vorbis_synthesis_blockin(), so the output timeline keeps its length and, once real packets resume, decoded samples are bit-identical to an intact stream apart from the concealed gap itself.


extern int      vorbis_synthesis_loss_notify(vorbis_dsp_state *v);

Parameters

v
The decoding vorbis_dsp_state in which a frame was lost.

Return Values

  • 0 on success.
  • OV_EINVAL if called before the first real block, or while decoded PCM is still waiting to be read.
