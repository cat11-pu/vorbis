Reusable track decoder

declared in "vorbis/reuse.h";

These functions decode a sequence of complete Vorbis tracks through one vorbis_reuse_decoder. When the next track has the same identification parameters and a byte-identical setup packet, the codebooks, floor/residue lookups, transforms, and PCM allocation are retained. Only the PCM overlap buffer, timeline counters, and block scratch storage are reset. A changed setup rebuilds the decoder.

The setup packet comparison is intentionally exact: a false match would silently decode with the wrong codebooks. Semantically equivalent but differently packed setup headers therefore take the rebuild path.

Track protocol

  1. For each track, pass identification, comment, and setup packets in stream order to vorbis_reuse_headerin().
  2. Decode audio packets with vorbis_reuse_decode(), pulling PCM with vorbis_reuse_pcmout() and consuming it with vorbis_reuse_read().
  3. Drain all PCM before the next identification packet. A switch with unread PCM returns OV_EINVAL.

Codebook and residual state are never used across a track boundary. After reuse, the first audio block starts from the same zeroed overlap state as a newly initialized decoder, so output is sample-identical to a full re-decode of the track.

Errors and edge cases

  • Headers out of order or a duplicate setup return OV_EBADHEADER.
  • A changed setup that fails to parse leaves the previous codebooks allocated; a subsequent valid track can still use or replace them.
  • A track with headers but no audio packets is valid and yields no PCM.
  • vorbis_reuse_free(NULL) is safe.
